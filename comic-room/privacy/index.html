개인정보처리방침

시행일 및 최종 수정일 2026년 11월 8일

코믹스 만화방은 책장, 관심 시리즈와 읽기 기록을 기기에 보관합니다. 사용자가 Google 계정 연결을 선택하면 같은 계정의 기기 사이에서 이 기록을 합치고 이어 보기 위해 Google Drive의 앱 전용 저장 공간을 사용합니다.

1. 사용하는 정보와 목적

  • 호의 원본 주소, 제목, 출판사, 시리즈, 시리즈 목록 주소와 회차 번호를 책장 분류와 동일한 호의 식별에 사용합니다.
  • 책장에 담은 상태와 변경 시각, 마지막으로 읽은 페이지, 전체 페이지 수, 열람 시각과 완독 여부를 저장하고 동기화합니다.
  • 관심 시리즈의 출판사, 시리즈 이름, 시리즈 목록 주소, 관심 등록·해제 상태와 변경 시각을 관심 시리즈 신간 선반 표시와 기기 간 동기화에 사용합니다.
  • 연결한 Google 계정의 이메일과 Drive 사용자 식별자를 올바른 계정에 연결하고 앱에 계정 정보를 표시하기 위해 기기에 저장합니다.
  • 설치 시 생성한 임의의 동기화 식별자를 기기별 Drive 파일의 구분에 사용합니다. 마지막 동기화 시각과 연결 상태도 기기에 저장합니다.

2. Google 계정 권한과 동기화

사용자가 앱에서 Google 계정을 선택하고 권한을 허용하면, 앱은 Google Drive의 앱 전용 저장 공간에 책장, 관심 시리즈와 읽기 기록 파일을 읽고 씁니다. 요청하는 권한은 https://www.googleapis.com/auth/drive.appdata입니다. 동기화 파일에는 위에서 설명한 호 정보, 책장 상태, 관심 시리즈 상태와 변경 시각, 읽기 기록과 설치별 식별자가 들어갑니다.

앱은 Google Play 서비스에서 발급한 접근 토큰을 요청 처리 중 메모리에서 사용하며, HTTPS로 Google Drive API에 연결합니다. Google 계정의 이메일과 Drive 사용자 식별자를 확인한 뒤 기록을 합칩니다. 같은 호의 읽기 위치와 책장 상태는 각각의 변경 시각을 비교해 적용합니다.

3. 보관 위치와 서비스 이용

책장, 관심 시리즈와 읽기 기록의 기기 사본은 Android 앱 저장 공간에, 동기화 사본은 연결한 계정의 Google Drive 앱 전용 공간에 보관합니다. 앱이 Google 사용자 정보를 사용하는 목적은 계정 확인과 사용자가 선택한 책장·관심 시리즈·읽기 기록 동기화입니다.

만화 페이지를 열면 기기가 원본 사이트와 이미지 제공 서버에 연결합니다. 대사의 글자 인식과 번역은 기기에서 처리하며, 처음 사용할 때 Google의 번역 모델을 내려받습니다. 원본 사이트와 Google 서비스의 데이터 처리는 각 서비스의 개인정보처리방침도 적용됩니다.

4. 연결 해제와 데이터 삭제

앱의 내 책장 → 동기화 → 이 기기에서 동기화 끄기로 해당 기기의 동기화 작업을 멈출 수 있습니다. 이 동작 후에도 기기의 책장·관심 시리즈·읽기 기록과 Drive 사본은 보관됩니다. Google 계정의 타사 앱 연결 관리에서 앱의 Google 접근 권한을 취소할 수도 있습니다.

기기의 사본과 계정 연결 정보를 삭제하려면 Android 설정에서 코믹스 만화방의 앱 데이터를 삭제합니다. Drive 사본을 삭제하려면 Google Drive 설정의 앱 관리에서 코믹스 만화방의 숨겨진 앱 데이터를 삭제합니다. 모든 사본을 지우려면 각 기기의 동기화를 끄고 기기 데이터와 Drive 데이터를 함께 삭제해야 합니다. 기기에 남은 기록은 다음에 연결할 때 다시 동기화될 수 있습니다.

5. 방침의 변경

앱의 데이터 처리 방식이 바뀌면 이 문서의 내용과 최종 수정일을 갱신합니다. Google 데이터의 이용 목적이나 요청 권한이 바뀌면 앱에서 변경 내용을 안내하고 필요한 동의를 받습니다.

6. 문의

앱과 데이터 처리에 관한 문의는 개발자 GitHub 프로필 또는 Google 권한 동의 화면에 표시되는 사용자 지원 연락처를 통해 할 수 있습니다.
