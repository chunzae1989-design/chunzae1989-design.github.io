Privacy Policy

Effective and last updated: August 23, 2026

Summary: Hermes Agent Tasks is a private, user-controlled automation. It uses Google Tasks data only to verify the connection, identify the user's task list, and create tasks that the user explicitly approves.

1. Scope

This Privacy Policy explains how Hermes Agent Tasks (the “Integration”) accesses and uses Google user data. The Integration is designed for personal use by its operator and is not offered as a public multi-user service.

2. Google data accessed

The Integration requests the Google Tasks OAuth scope. Depending on the operation approved by the user, it may access:

  • Google Tasks list names and identifiers, so the user can select a destination list;
  • task titles, notes, due dates, and status when needed to perform or verify a requested Tasks operation;
  • the ability to create a task that the user has explicitly approved.

The current personal workflow does not automatically complete or delete Google Tasks.

3. How Google data is used

Google user data is used only to provide the user-requested Google Tasks handoff. A local call-recording workflow may propose possible follow-up items, but no proposed item is transferred to Google Tasks until the user explicitly approves it.

The Integration does not use Google user data for advertising, profiling, credit decisions, or any unrelated purpose.

4. Storage and security

  • OAuth credentials are stored in a user-controlled local macOS environment, not in this public website.
  • Local credential files are restricted to the operating-system account that runs the Integration.
  • Approved tasks are stored by Google in the user's Google Tasks account.
  • Local workflow files may temporarily retain a candidate task title, notes, approval state, and operational logs.
  • OAuth access tokens, refresh tokens, and client secrets are never published in this website or repository.

5. Sharing and sale of data

The Integration does not sell Google user data. It does not share Google user data with advertisers, data brokers, or unrelated third parties. Data is transmitted to Google only as required to perform the Tasks operation selected by the user.

6. Retention and deletion

Tasks created through the Integration remain in Google Tasks until the user edits or deletes them. The user may delete local candidate and log files from the local environment at any time. OAuth access can be revoked from the Google Account third-party connections page; local credentials can also be deleted to disconnect the Integration.

7. Google API Services User Data Policy

The Integration's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes to this policy

This policy may be updated when the Integration's functionality or data practices change. The effective date at the top of this page will be revised when material changes are published.

9. Contact

Questions about this policy can be directed to the developer through the developer's GitHub profile or the user-support address shown on the Google OAuth consent screen.
