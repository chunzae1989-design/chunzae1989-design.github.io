Private personal automation

Follow-up tasks, created only after approval.

Hermes Agent Tasks connects a user-controlled call-recording workflow to Google Tasks. It helps identify possible follow-up items, asks the user to review them, and creates a task only when the user explicitly approves it.

Read the privacy policy View terms of service
01 · Review

Candidate detection

The local workflow extracts possible follow-up items and presents them for review. A candidate is not a Google Task.

02 · Approve

User control

The user decides whether an item should be transferred. No task is created merely because a recording was processed.

03 · Create

Google Tasks handoff

After explicit approval, the integration creates the selected task in the user's chosen Google Tasks list.

Designed for one user's private workflow This is not a public SaaS product. OAuth credentials remain in a user-controlled local environment, and Google user data is not sold, advertised against, or shared with third parties.
